# 0.3.7

- Start now detects an incomplete registered installation and repairs it automatically instead of asking customers to choose between moved and deleted folders.
- Recovery stops owned executor processes, creates a verified backup, restores missing program files and starts the original data location.
- Existing customer databases, settings, AI keys, server configuration and WhatsApp sessions remain preserved.
- Missing runtime components are restored only when required.
- Customer packages keep the protected runtime, protected browser assets and obfuscated Chrome extension without source maps.
